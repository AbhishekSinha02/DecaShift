📲 Install App

Add Donnibo to your home screen for instant daily access.

  1. Open Donnibo in Chrome
  2. Tap ⋮ → Add to Home screen
  3. Tap Add
Microsoft Edge:
  1. Click ⋯ → Apps → Install this site as an app
  2. Click Install
  3. Right-click icon in taskbar → Pin to taskbar
Google Chrome:
  1. Click ⋮ → Save and share → Create shortcut
  2. Check "Open as window" → Create
  1. Tap the Share button ⬆ (bottom of Safari)
  2. Tap "Add to Home Screen"
  3. Tap "Add" in the top right
