# Feature: Collectibles & Mystery Box

## Overview
A variable-reward system that drops stickers, XP bonuses, or streak freezes from a "Mystery Box." The box opens after completing the Daily Quest. Stickers are Donnibo expression variants collected in a sticker album. The system uses weighted probability so users never receive a duplicate sticker or a wasted reward.

---

## User Flows

### Flow 1: Earning a Mystery Box

**Entry point:** User completes the Daily Quest (all 3 objectives done).

1. +50 XP is awarded (quest complete bonus)
2. Mystery Box reward is generated by `Collectibles.rollReward()`
3. A **reward notification card** slides up from the bottom of the Home screen
4. Card shows:
   - Reward type icon
   - Reward name (e.g., "Victory Donnibo sticker!" or "+50 XP" or "❄ Streak Freeze")
5. User taps **"Claim"** → reward is applied and notification dismisses

---

### Flow 2: Getting a Sticker Reward

1. Box rolls a new sticker (probability: 50% if any unowned stickers remain)
2. Reward card shows the sticker image + name + rarity badge
3. User claims → sticker is added to their collection
4. Sticker album updates: new sticker appears with a "NEW" ribbon

---

### Flow 3: Getting an XP Reward

1. Box rolls XP (probability: varies — fallback when all stickers are owned)
2. Reward card shows "+50 XP" or "+100 XP" (level box gives more)
3. User claims → XP is added; level-up fires if threshold crossed

---

### Flow 4: Getting a Streak Freeze

1. Box rolls a freeze (if user has fewer than 2 stored)
2. Reward card shows "❄ Streak Freeze" — one saved day for missing practice
3. User claims → `Storage.streak.freezes` increments

---

### Flow 5: Viewing the Sticker Album

**Entry point:** Settings → Collectibles, or a dedicated album button on Journey screen.

1. Album shows all 7 sticker slots
2. **Owned stickers**: full-color with name and rarity badge
3. **Unowned stickers**: greyed-out silhouette with "???" label
4. Stickers with "NEW" ribbon = earned but not yet viewed in album
5. Viewing the album marks all unseen stickers as seen (ribbon disappears)
6. Each sticker shows how it's earned (e.g., "Mystery box" / "Streak / level box")

---

## Reward Roll Probability

```
Roll < 0.50 AND unowned stickers exist → New sticker (random from unowned)
Roll < 0.80                            → XP bonus (50 standard, 100 on level box)
Roll >= 0.80 AND freezes < 2           → Streak Freeze
Roll >= 0.80 AND freezes >= 2          → XP bonus (no wasted reward)
```

This means:
- If you haven't collected all stickers: 50% chance of a new one each box
- Once all stickers are owned: all rolls become XP or freeze

---

## Storage

- Owned sticker IDs stored in `donnibo_collectibles` (JSON array of IDs)
- Seen sticker IDs stored in `donnibo_stickers_seen` (for NEW ribbon logic)
- Never stores duplicates — `grant()` checks ownership before writing

---

## Box Types

Currently all boxes are the same type (quest completion box). Future box types planned:
- **Streak box**: drops On-Fire sticker more frequently
- **Level milestone box**: drops Level-Up sticker, gives 100 XP
