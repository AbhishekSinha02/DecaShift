# Feature: Flash Drills

## Overview
Speed-based timed drills for instant mental-math and recall. Five drill types: Multiplication Tables, Squares, Cubes, Formulas (Science), and GK Speed Round. Each drill is a rapid-fire 10-question session with a countdown timer per question. Personal bests are tracked; users can share their drill score.

---

## User Flows

### Flow 1: Accessing Flash Drills

**Entry point:** Home screen → Flash Drills shelf (horizontal scroll row near top of page).

1. User sees a horizontal shelf of drill cards, each showing:
   - Drill name (e.g., "Tables", "Squares", "Formulas")
   - Short description ("2×2 to 12×12")
   - Personal best time (if available), e.g., "PB: 1:24"
   - "Start" button

2. **User taps a drill card** → drill screen loads

---

### Flow 2: Playing a Flash Drill

**Entry point:** User taps a drill card from the shelf.

1. **Drill screen loads** showing:
   - Drill name header
   - **Countdown timer**: e.g., 10 seconds per question (shown as a shrinking bar or circle)
   - **Question text**: large, e.g., "7 × 8 = ?"
   - **4 answer option buttons**: auto-generated correct answer + 3 plausible wrong answers

2. **User taps an answer**:
   - **Correct**: card flashes green, score increments, next question loads immediately
   - **Wrong**: card flashes red, correct answer highlights, brief pause, next question loads
   - **Timeout** (timer reaches 0): counted as wrong, next question loads

3. **After 10 questions** → Drill result screen

---

### Flow 3: Drill Result

1. **Result shows**:
   - Questions correct out of 10
   - Total time taken
   - Personal Best badge (🏅 "New PB!") if this session beat the stored best
   - XP earned (+15 XP for completing a drill)
   - Daily Quest "Drill" objective marked complete (updates the quest bar)

2. **Action buttons**:
   - **"Share Score"** → opens Share Card flow (see Feature 12)
   - **"Play Again"** → same drill restarts
   - **"Back to Home"** → Home screen

## Drill Types & Data Sources

| Drill | Questions | Source |
|---|---|---|
| Multiplication Tables | 2×2 to 12×12 (121 possible) | Generated in-memory by `_buildTablesBank()` |
| Squares | 1² to 25² | Generated by `_buildSquaresBank()` |
| Cubes | 1³ to 15³ | Generated by `_buildCubesBank()` |
| Science Formulas | Physics / Chemistry formulae | Loaded from question bank JSON |
| GK Speed Round | General Knowledge questions | Loaded from GK question bank |

Questions are shuffled on every drill start — no two sessions are identical.

---

## Wrong Answer Generation

Wrong answers are mathematically plausible (not random):
- **Tables**: `answer ± (1–4 multiples of the multiplier)`
- **Squares**: `answer ± small even multiples of n`
- **Cubes**: `answer ± n²` offsets

This ensures the difficulty is real, not trivially easy to eliminate.

---

## Personal Best Tracking

- PB is stored per drill type in localStorage
- Format: `{ timeSeconds: 84, score: 10, date: "2026-05-31" }`
- PB is shown on the drill card on Home and on the result screen
- A "New PB!" celebration fires if current session beats the stored best

---

## XP Awarded

| Action | XP |
|---|---|
| Drill complete | +15 |
| Perfect drill (10/10) | +15 + perfect bonus (applies standard set-complete rules) |

---

## Daily Quest Integration

Completing any one flash drill marks the **Drill** objective in the Daily Quest as done. Only one drill per day is needed — extra drills don't double-count for the quest but are still tracked for PB purposes.
